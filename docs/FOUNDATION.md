# Playable foundation

The application and backend are TypeScript. The native SpacetimeDB module imports the same deterministic simulation as the React frontend. See the root README for local commands and docs/SPACETIMEDB.md for your cloud connection steps.

Implemented systems include construction and terrain conversion, resource production/consumption, technology prerequisites and class affinities, a finite global exchange with dynamic prices, recurring trade, aid and diplomacy, shared climate and ocean health, geological and climate hazards, cross-border consequence ledgers, quizzes and recovery, historical debriefs, and endgame scoring.

The map uses the original repository world image and 16 castle provinces. Gameplay districts are currently grouped beneath those provinces. The pixel HUD places navigation at the world edge and resources at the bottom; inspectors and strategy systems open over the map.

Local practice works without a server. Online rooms use identity-bound seats, revision checks, ready locks and server quiz clocks. The local two-identity integration check exercises a real published SpacetimeDB module.

The roadmap explicitly records remaining province simulation, portrait dialogue, balance, accessibility, and production multiplayer work. This foundation is a substantial playable base, not a claim that every proposed expansion or reference artboard is complete.
